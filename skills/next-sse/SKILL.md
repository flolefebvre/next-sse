# next-sse

**Read `node_modules/@flefebvre/next-sse/docs/index.md` first.**

The manual ships inside the package, so it describes the exact version installed in this project.
`index.md` is a router: it says which file to load for the job at hand, lists the six subpath
entry points, and states the rules that hold everywhere.

This skill holds no documentation of its own on purpose — content here could disagree with the
installed version. If the docs folder is missing, the dependency is not installed, or is a version
that predates shipped docs.
